# 🎯 Quiz Game

An interactive and engaging Quiz Game built using React, JavaScript, HTML, and CSS.

## 🚀 Live Demo

https://vidyakori15.github.io/quiz-game/

## ✨ Features

- 🎯 Multiple-choice quiz questions
- ☑️ Single and multiple-select questions
- ✍️ Fill-in-the-blank questions
- ⏱️ Timer
- 💡 Hints
- 🏆 High-score tracking
- 📋 Answer review
- 🌙 Dark and light mode
- 👤 Player name support
- 📊 Score calculation
- 📱 Responsive design

## 🛠️ Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
